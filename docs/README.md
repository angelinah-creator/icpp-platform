# Documentation projet

## Documents disponibles

- `rapport-avancement-projet.md` : vision synthese de l'avancement.
- `documentation-responsables-projet.md` : documentation detaillee de pilotage et des parcours utilisateurs.
- `guide-test-fonctionnel.md` : campagne de recette manuelle multi-role.
- `guide-tests-unitaires.md` : mode d'emploi de la nouvelle base de tests unitaires.

## Usage recommande

1. lire le rapport d'avancement pour la vision globale,
2. utiliser la documentation responsables projet pour le cadrage,
3. executer le guide de test fonctionnel pendant la recette,
4. utiliser le guide des tests unitaires pour la qualite technique continue.
