# Guide Utilisateur : Espace Technicien / Auditeur ICPP

Bienvenue sur votre espace intervenant ICPP Conformité. Ce guide vous explique comment gérer vos missions sur le terrain et assister les clients.

## 1. Votre Tableau de Bord

Votre tableau de bord récapitule vos missions en cours :
- Les **Tâches** qui vous sont assignées (mise à jour DUERP, audit suite à un signalement, etc.).
- Les **Audits** que vous avez commencés et qui ne sont pas encore terminés.

## 2. Réaliser un Audit

L'audit est l'étape essentielle pour générer le DUERP du client.
- Allez dans **"Mes Audits"** et cliquez sur **"Nouvel Audit"**.
- Sélectionnez l'entreprise cliente.
- Le formulaire d'audit est divisé en plusieurs étapes (Informations, Affichages, Registres, et Évaluation des risques).
- Pour chaque risque identifié selon le métier du client, indiquez le **Niveau de maîtrise** (de "Aucune" à "Maîtrise optimale").
- Le système calcule automatiquement le **Risque Résiduel** et la priorité d'action.
- À la fin, marquez l'audit comme **Terminé**.

## 3. Assigner un Abonnement et Valider le Paiement

Une fois l'audit terminé, vous devez proposer un abonnement au client.
- Dans le détail de l'audit terminé, cliquez sur **"Procéder au paiement"**.
- Sélectionnez le plan d'abonnement ICPP approprié.
- Si le client paie en **Espèces ou par Chèque** sur place, vous pouvez le déclarer.
- Si vous avez les droits, vous pouvez valider ce paiement immédiatement. Cela débloquera l'espace du client, génèrera sa facture, son contrat et son DUERP.

## 4. Mes Tâches et Rapports

- L'administrateur peut vous assigner des missions via le menu **"Mes Tâches"**.
- Une fois une tâche terminée (par exemple, une visite de contrôle), vous pouvez rédiger un **Rapport** de visite, qui sera consultable par l'administrateur.

## 5. Les Signalements Clients

- Vous pouvez être notifié si l'un de vos clients émet un **Signalement** (accident, déménagement).
- Dans ce cas, une tâche vous est généralement assignée pour prendre contact avec le client et évaluer si une mise à jour de l'audit est nécessaire.
